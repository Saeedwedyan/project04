# Personal Portfolio 
 
## Description 
 
This project is a personal portfolio website built from scratch using HTML5, CSS3, and JavaScript. 
 
## Sections 
 
- About Me 
- Skills 
- Projects 
- Hobbies 
- Contact 
 
## Technologies 
 
- HTML5 
- CSS3 
- JavaScript ES6+ 
 
## JavaScript Feature 
 
The website includes a theme switcher button. 
When the user clicks the button, JavaScript toggles the `dark` class on the body, which changes the page styles. 
 
## Responsive Design 
 
The website uses Flexbox and CSS media queries to provide a responsive layout for desktop and mobile screens.
